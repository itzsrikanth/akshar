## Prose

- ಕನ್ನಡದಲ್ಲಿ ಒಟ್ಟು 49 ಅಕ್ಷರಗಳಿವೆ. ಇವುಗಳನ್ನು ವರ್ಣಗಳೆಂದು ಕರೆಯುತ್ತಾರೆ. ಈ ಅಕ್ಷರಗಳ ಕ್ರಮಬದ್ಧ ಜೋಡಣೆಗೆ ‘ವರ್ಣಮಾಲೆ’ ಅಥವಾ ‘ಅಕ್ಷರಮಾಲೆ’ ಎಂದು ಹೆಸರು.
- ವರ್ಣಮಾಲೆಯಲ್ಲಿ ಮೂರು ವಿಧಗಳು ಅ) ಸ್ವರಾಕ್ಷರಗಳು ಆ) ವ್ಯಂಜನಾಕ್ಷರಗಳು ಇ) ಯೋಗವಾಹಗಳು
- ಸ್ವತಂತ್ರವಾಗಿ ಉಚ್ಚರಿಸಲಾಗುವ ಅಕ್ಷರಗಳು ಸ್ವರಾಕ್ಷರಗಳು. ಒಟ್ಟು ಸ್ವರಾಕ್ಷರಗಳು 13.
- ಸ್ವರಾಕ್ಷರಗಳಲ್ಲಿ ಎರಡು ವಿಧ.: 1) ಹ್ರಸ್ವಸ್ವರಗಳು 2) ದೀರ್ಘಸ್ವರಗಳು
- 1) ಹ್ರಸ್ವಸ್ವರ - ಒಂದು ಮಾತ್ರಾ ಕಾಲದಲ್ಲಿ ಉಚ್ಚರಿಸಲಾಗುವ (ಅ, ಇ, ಉ, ಋ, ಎ, ಒ) ಅಕ್ಷರಗಳು ಹ್ರಸ್ವಸ್ವರಗಳು.
- 2) ದೀರ್ಘಸ್ವರ - ಎರಡು ಮಾತ್ರಾ ಕಾಲದಲ್ಲಿ ಉಚ್ಚರಿಸಲಾಗುವ (ಆ, ಈ, ಊ, ಏ, ಐ, ಓ, ಔ) ಅಕ್ಷರಗಳು ದೀರ್ಘಸ್ವರಗಳು.
- ಸ್ವರಗಳ ಸಹಾಯದಿಂದ ಉಚ್ಚರಿಸಲಾಗುವ ಅಕ್ಷರಗಳು ವ್ಯಂಜನಾಕ್ಷರಗಳು. (ಉದಾ : ಕ್ + ಅ = ಕ ; ಚ್ + ಅ = ಚ) ಒಟ್ಟು ವ್ಯಂಜನಾಕ್ಷರಗಳು = 34
- ವ್ಯಂಜನಾಕ್ಷರಗಳಲ್ಲಿ ಎರಡು ವಿಧ : 1) ವರ್ಗೀಯ ವ್ಯಂಜನಗಳು 2) ಅವರ್ಗೀಯ ವ್ಯಂಜನಗಳು
