- ಸಂಧಿಗಳು
ಎರಡು ಅಕ್ಷರಗಳು ಕಾಲ ವಿಳಂಬವಿಲ್ಲದೆ ಅರ್ಥಕ್ಕೆ ಅನುಸಾರವಾಗಿ ಸೇರುವುದೇ ಸಂಧಿ.
ಉದಾಹರಣೆಗೆ :
ಮಳೆ + ಕಾಲ = ಮಳೆಗಾಲ
ಹೀಗೆ ಒಂದು ಪದ ಇನ್ನೊಂದು ಪದದೊಡನೆ ಸೇರಿದಾಗ ಪೂರ್ವಪದದ ಅಂತ್ಯದಲ್ಲಿ ಮತ್ತು ಉತ್ತರಪದದ ಆದಿಯಲ್ಲಿ ಮೂರು ಬಗೆಯ ಕಾರ್ಯಗಳು ನಡೆಯಬಹುದು. ಅಕ್ಷರವೊಂದು ಲೋಪವಾಗಬಹುದು, ಇನ್ನೊಂದು ಆಗಮಿಸಬಹುದು, ಒಂದು ಅಕ್ಷರ ಹೋಗಿ ಅದರ ಸ್ಥಾನದಲ್ಲಿ ಬೇರೆಯೇ ಅಕ್ಷರ ಬರಬಹುದು. ಇದನ್ನು ‘ಸಂಧಿಕಾರ್ಯ’ ಎನ್ನುವರು.
ಪೂರ್ವಪದ + ಉತ್ತರಪದ = ಸಂಧಿಕಾರ್ಯ
ಮಾತು + ಅನ್ನು = ಮಾತನ್ನು
(ಉ) + (ಅ) = ಉ ಲೋಪ
ಸಂಧಿಯ ವಿವಿಧ ಪ್ರಕಾರಗಳ ಬಗ್ಗೆ ಮುಂದಿನ ಪಾಠದಲ್ಲಿ ತಿಳಿದುಕೊಳ್ಳೋಣ.

## Exercise grammar-A

- 1. ಸಂಧಿ ಎಂದರೇನು? ಒಂದು ಉದಾಹರಣೆ ಕೊಡಿ.
  - Deva: 1. संधि एंदरेनु? ओंदु उदाहरणे कोडि.
  - Latn: 1. sandhi endarēnu? ondu udāharaṇe koḍi.
  - en-IN: 1. What is sandhi? Give one example.
  - hi-IN: 1. संधि क्या है? एक उदाहरण दीजिए।
- 2. ಸಂಧಿ ಕಾರ್ಯ ಎಂದರೇನು?
  - Deva: 2. संधि कार्य एंदरेनु?
  - Latn: 2. sandhi kārya endarēnu?
  - en-IN: 2. What is sandhi-karya?
  - hi-IN: 2. संधि कार्य क्या है?
- 3. ತೆನೆ + ಅನ್ನು. ಇದರಲ್ಲಿ ಪೂರ್ವಪದ, ಉತ್ತರಪದ ಯಾವುದು ತಿಳಿಸಿರಿ. ಇದರಲ್ಲಿ ನಡೆದ ಸಂಧಿಕಾರ್ಯವನ್ನು ಬರೆಯಿರಿ.
  - Deva: 3. तेने + अन्नु. इदरल्लि पूर्वपद, उत्तरपद यावुदु तिळिसिरि. इदरल्लि नडेद संधिकार्यवन्नु बरेयिरि.
  - Latn: 3. tene + annu. idaralli pūrvapada, uttarapada yāvudu tiḷisiri. idaralli naḍeda sandhikāryavannu bareyiri.
  - en-IN: 3. tene + annu. State which is the first word and which the second. Write the sandhi process that occurred.
  - hi-IN: 3. तेने + अन्नु। इसमें पूर्वपद, उत्तरपद बताइए। संधिकार्य लिखिए।
- 4. ಈ ಪದಗಳನ್ನು ಬಿಡಿಸಿ ಬರೆಯಿರಿ. ಸಂಧಿ ಕಾರ್ಯ ಹೇಳಿರಿ. ಸಕ್ಕರೆಯಾಯಿತು, ಕೆಟ್ಟವಳೇನೂ, ದುಃಖಿತನಾದನು
  - Deva: 4. ई पदगळन्नु बिडिसि बरेयिरि. संधि कार्य हेळिरि. सक्करेयायितु, केट्टवळेनू, दुःखितनादनु
  - Latn: 4. ī padagaḷannu biḍisi bareyiri. sandhi kārya hēḷiri. sakkareyāyitu, keṭṭavaḷēnū, duḥkhitanādanu
  - en-IN: 4. Split these words and write. State the sandhi process: sakkareyayitu, kettavalenu, duhkitanadanu
  - hi-IN: 4. इन पदों को तोड़कर लिखिए। संधि कार्य बताइए। सक्करेयायितु, केट्टवळेनु, दुःखितनादनु

## Exercise language-exercise-A

- 1. ವಿವಿಧ ವಚನಕಾರರ ವಚನಗಳನ್ನು ಸಂಗ್ರಹಿಸಿ ಓದಿರಿ.
  - Deva: 1. विविध वचनकारर वचनगळन्नु संग्रहिसि ओदिरि.
  - Latn: 1. vividha vacanakārara vacanagaḷannu saṅgrahisi ōdiri.
  - en-IN: 1. Collect and read vachanas of various vachana poets.
  - hi-IN: 1. विभिन्न वचनकारों के वचन संगृहीत कर पढ़िए।
- 2. ಧ್ವನಿ ಸುರುಳಿಯಲ್ಲಿರುವ ವಚನಗಳನ್ನು ಆಲಿಸಿರಿ.
  - Deva: 2. ध्वनि सुरुळियल्लिरुव वचनगळन्नु आलिसिरि.
  - Latn: 2. dhvani suruḷiyalliruva vacanagaḷannu ālisiri.
  - en-IN: 2. Listen to vachanas on audio recordings.
  - hi-IN: 2. ध्वनि रिकॉर्डिंग में वचन सुनिए।
- 3. ಸಾಮೂಹಿಕವಾಗಿ ವಚನಗಳನ್ನು ಹಾಡಿರಿ.
  - Deva: 3. सामूहिकवागि वचनगळन्नु हाडिरि.
  - Latn: 3. sāmūhikavāgi vacanagaḷannu hāḍiri.
  - en-IN: 3. Sing vachanas in a group.
  - hi-IN: 3. सामूहिक रूप से वचन गाइए।
- 4. ವಚನಕಾರರ ಜೀವನ ಚರಿತ್ರೆಗಳನ್ನು ಓದಿರಿ.
  - Deva: 4. वचनकारर जीवन चरित्रेगळन्नु ओदिरि.
  - Latn: 4. vacanakārara jīvana caritregaḷannu ōdiri.
  - en-IN: 4. Read life histories of vachana poets.
  - hi-IN: 4. वचनकारों की जीवनियाँ पढ़िए।
