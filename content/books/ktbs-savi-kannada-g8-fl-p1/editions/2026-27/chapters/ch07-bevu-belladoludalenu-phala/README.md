## Exercise C · ಇ. ಕೆಳಗಿನ ಹೇಳಿಕೆಗಳಿಗೆ ಸಂದರ್ಭಸಹಿತ ಸ್ವಾರಸ್ಯವನ್ನು ಬರೆಯಿರಿ. · इ. कॆळगिन हेळिकॆगळिगॆ संदर्भसहित स्वारस्यवन्नु बरॆयिरि. · i. kèḻagina heḻikègaḻigè saṃdarbhasahita svārasyavannu barèyiri. · C. Answer the following questions. · इ. निम्नलिखित प्रश्नों के उत्तर दीजिए।
